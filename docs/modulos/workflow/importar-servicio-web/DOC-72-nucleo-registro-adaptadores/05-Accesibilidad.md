# Accesibilidad

El modal usa `role="dialog"`, `aria-modal`, título asociado y estado `aria-live="polite"`. Al abrir enfoca el cierre; al cerrar devuelve foco al disparador. Tab y Shift+Tab permanecen dentro del diálogo y Escape cierra el recorrido antes de cualquier ejecución activa.

Los estilos incluyen foco visible, contraste para errores, scroll interior y presentación móvil a altura completa.
