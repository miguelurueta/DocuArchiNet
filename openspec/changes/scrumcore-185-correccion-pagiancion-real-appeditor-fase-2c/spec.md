# Spec: SCRUMCORE-185 Fase 2C

## Criterios de aceptacion (implementables)

- Paste largo no rompe el editor y conserva links/marks inline.
- Paste con listas mantiene una continuidad razonable (estructura no se corrompe).
- Imagen que no cabe se mueve completa a la siguiente hoja (no se parte).
- Documentos multipagina siguen editables con rendimiento razonable (sin loops).

## Validacion minima

- paste de texto largo con links
- paste de contenido con listas
- imagen grande que no cabe
- documento de varias paginas con ediciones sucesivas
