# DOC-111 — Diseño de integración

Corrección solicitada por el usuario, 2026-10-30 (D-03/D-04/D-10/D-11): se elimina la habilitación mediante claves `Doc111.*` en Web.config. Extensiones y límite funcional por archivo proceden de la versión publicada existente. La composición reutiliza el tamaño de petición ASP.NET y el límite JSON existentes; la vigencia del plan reutiliza el timeout de sesión. No se introduce un cupo funcional acumulado de lote ni nuevos cupos PDF. Los límites de representación del parser se mantienen; los presupuestos explícitos siguen disponibles para consumidores internos que los proporcionen. La limpieza no tiene política por defecto: permanece deshabilitada y requiere inyección explícita de una política vigente para su capacidad interna. Esta decisión sustituye los requisitos de appSettings y presupuestos de activación de los cortes históricos inferiores. No cambia publicación, esquema, almacenamiento legacy ni SII.

Estado: refinamiento autorizado para continuar el flujo el 2026-10-27; implementación progresiva desde el repositorio local principal. Base de diseño 6313f91f. Se mantienen WebForms/VB.NET 4.6.1, JavaScript, ASMX/ASHX y MySQL 5.1. La aprobación no equivale a implementación terminada, esquema aplicado o autorización de efectos reales.
