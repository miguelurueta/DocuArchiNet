- 
- Implementar la base del modulo reusable `DigitalizacionDocumental` para que pueda abrirse desde cualquier modulo consumidor de la aplicacion.
- 
- El modulo debe:
- 
- - recibir contexto documental externo;
- - soportar modo `crear`;
- - soportar modo `adjuntar`;
- - exponer callbacks de resultado;
- - mantener estado interno aislado;
- - no depender del modulo consumidor;
- - preparar la integracion con scanner, metadata, upload y APIs backend;
- - soportar reinicializacion segura por cambio de contexto;
- - permitir que otros modulos usen digitalizacion como capacidad reusable.
- 
- ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- ## REGLA ARQUITECTONICA OBLIGATORIA
- ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 
- `DigitalizacionDocumental` debe implementarse como capacidad reusable desacoplada.
- 
- Esto implica:
- 
- - no conocer consumidores especificos;
- - no conocer rutas especificas;
- - no conocer modulos especificos;
- - no leer datos desde contexto global externo;
- - no depender de stores de otros modulos.
- 
- El unico contrato de entrada permitido es:
- 
- ```txt
- DigitalizacionContext
- ```
- 
- ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 
- El contexto recibido desde el consumidor:
- 
- ```txt
- DigitalizacionContext
- ```
- 
- es la unica fuente valida para inicializar el flujo.
- 
- PROHIBIDO:
- 
- - reconstruir contexto desde URL;
- - reconstruir contexto desde localStorage;
- - reconstruir contexto desde Session;
- - reconstruir contexto desde variables globales.

- ## CONTRATO FRONTEND OBLIGATORIO
- ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 
- Crear tipos estrictos:
- 
- ```ts
- export type DigitalizacionModo = "crear" | "adjuntar";
- 
- export type DigitalizacionContext = {
-   modo: DigitalizacionModo;
-   nombreGabinete: string;
-   radicado?: string;
-   idTramite?: number;
-   tipoTramite?: string;
-   idTareaWorkflow?: number;
-   idRutaWorkflow?: number;
-   idDocumentoDestino?: number;
-   requiereMetadata?: boolean;
-   titulo?: string;
-   sourceModule?: string;
- };
- 
- export type DigitalizacionResult =
-   | {
-       accion: "documento-creado";
-       idDocumento: number;
-       nombreGabinete: string;
-       numeroPaginas?: number;
-       trd?: DigitalizacionTrdMetadata;
-     }
-   | {
-       accion: "documento-adjuntado";
-       idDocumento: number;
-       nombreGabinete: string;
-       numeroPaginas?: number;
-     }
-   | {
-       accion: "cancelado";
-     };
- 
- export type DigitalizacionDocumentalProps = {
-   open: boolean;
-   context: DigitalizacionContext | null;
-   onClose: () => void;
-   onCompleted: (result: DigitalizacionResult) => void;
-   onError?: (error: DigitalizacionFunctionalError) => void;
- };
- ```
- 
- ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- ## VALIDACION CONTRACTUAL RUNTIME OBLIGATORIA
- ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 
- Nunca asumir que `context` es valido.
- 
- Validar explicitamente:
- 
- - `open = true` y `context = null`;
- - `modo` inexistente;
- - `modo` invalido;
- - `nombreGabinete` vacio;
- - `nombreGabinete` whitespace;
- - si `modo = adjuntar`, `idDocumentoDestino` requerido y mayor a cero;
- - `idDocumentoDestino <= 0` cuando `modo = adjuntar`;
- - `context` parcial;
- - propiedades `undefined` requeridas;
- - si `requiereMetadata = true`, preparar estado para metadata;
- - no permitir guardar/adjuntar si el contexto es invalido.
- 
- Si falla:
- 
- - mostrar error funcional controlado;
- - no inicializar scanner;
- - no iniciar upload;
- - no llamar APIs.
- - no permitir guardar.
- 
- Mensajes funcionales esperados:
- 
- ```txt
- El contexto documental es obligatorio.
- nombreGabinete es obligatorio.
- idDocumentoDestino es obligatorio para modo adjuntar.
- ```

- ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
