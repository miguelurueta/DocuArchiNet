## ADDED Requirements

### Requirement: Validacion final de comportamiento
El sistema SHALL validar con pruebas que `AppCollapseRail` mantiene el contrato
definido en fases previas (colapso, rail y responsive).

#### Scenario: Suite de pruebas completa
- **WHEN** se ejecutan las pruebas del componente
- **THEN** se valida el comportamiento en variants y placements

### Requirement: Documentacion consolidada
El sistema SHALL contar con README actualizado y ejemplos consistentes con el
comportamiento actual del componente.

#### Scenario: README actualizado
- **WHEN** el desarrollador consulta la documentacion
- **THEN** encuentra ejemplos para desktop y mobile
