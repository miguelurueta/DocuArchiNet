# Casos de uso implementados

| Caso | Actor y precondiciones | Flujo principal | Alternativas y errores | Resultado | Endpoint / participantes |
|---|---|---|---|---|---|
| CU-01 Resolver capacidades | Usuario Workflow autenticado; gate activo; sesión y tarea `ENLASE` coherentes | Valida envelope, reconstruye contexto, resuelve `INTEGRACIONSII` y publica tres capacidades | Gate/solicitud/contexto/configuración inválidos: envelope seguro | `ResolveCapabilitiesResponseDto`, HTTP 200 | `POST ...asmx/ResolveCapabilities`; `ResolveCapabilities`, `TryBuildImportContext`, `ResolveCapabilitiesAsync` |
| CU-02 Consultar anexos | CU-01; `Capability=ANEXOS_RADICADO_ENLASE` | Reconstruye recibo/barcode; obtiene token; consulta radicado; mapea `imagenes` | Sin `imagenes`: lista vacía; fila inválida, `idanexo` vacío/duplicado, SII/HTTP inválido: `Error.Codigo` saneado | `QueryItemsResponseDto`, HTTP 200, sin mutación documental | `POST ...asmx/QueryItems`; `QueryItems`, `QueryAnnexesAsync`, `MapQuery` |
| CU-03 Crear preview | Contexto válido; `ExternalKey=idanexo` | Reconsulta radicado, resuelve identidad, descarga contenido permitido y persiste descriptor opaco | No encontrado/duplicado; host/tipo/tamaño inválido; persistencia no disponible: envelope seguro | `GetPreviewResponseDto`, HTTP 200 | `POST ...asmx/GetPreview`; `GetPreview`, `GetAnnexPreviewContentAsync`, `Resolve`, `Create` |
| CU-04 Inspeccionar descriptor | Gate activo; descriptor, sesión, usuario, tarea y proveedor coinciden | `HEAD` lee metadatos disponibles | Inválido, vencido, consumido o ajeno: 404; método no permitido: 405; excepción: 503 | Cabeceras, HTTP 200 sin cuerpo | `HEAD workflow/ImportarServicioWebPreview.ashx?d=...`; `ProcessRequest`, `Head`, `GetAvailableMetadata` |
| CU-05 Consumir preview | Mismas precondiciones de CU-04 | `GET` reclama atómicamente, transmite y marca consumido | Claim perdido/contenido inconsistente: 404; excepción previa a cabeceras: 503 | Binario inline, HTTP 200, descriptor consumido | `GET workflow/ImportarServicioWebPreview.ashx?d=...`; `Claim`, `ClaimAndLoad`, `Complete`, `MarkConsumed` |
| CU-06 Compatibilidad de constancias | Capability vacía | El proveedor conserva la rama de consulta/preview histórica | Capability no vacía y desconocida: `SII_CAPABILITY_UNSUPPORTED` | Contrato histórico preservado | `SiiImportProvider.QueryItemsAsync/GetPreviewContentAsync` |

No existe bifurcación por rol o grupo dentro de DOC-80. La autorización implementada depende del gate general, sesión Workflow válida, coincidencia usuario/grupo/ruta/tarea y actividad `ENLASE`; por eso no se documenta una regla de rol inexistente.
