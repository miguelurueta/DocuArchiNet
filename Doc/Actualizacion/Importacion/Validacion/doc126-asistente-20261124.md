El usuario pulsa Crear plantilla desde Excel, selecciona un XLS/XLSX, analiza la hoja y revisa la propuesta de campos. Los encabezados de origen se conservan exactamente; destinos válidos se normalizan y desambiguan. Se elige el campo único entre los destinos actuales, con actualización al renombrar o quitar campos. Guardar usa el CAS vigente y no importa. El File se conserva sólo en memoria; Recibir archivo envía la recepción normal y contrasta su hash antes de habilitar preparación. Cambiar archivo/contexto o recrear el host invalida las referencias. Al recargar debe elegirse nuevamente el libro.

La propuesta recorre toda la hoja (no sólo muestra) con límites actuales de 20000 filas/10 MB, encabezados en fila 1 y hasta 256 columnas. Muestra hasta 25 filas y abrevia valores a 120 caracteres sin abreviar los datos de importación. Códigos y formatos 00000 se proponen como texto; números compatibles como DECIMAL, fechas tipadas sin hora como DATE; tipos mezclados o fechas textuales permanecen texto. VARCHAR incorpora margen de longitud, hasta el límite creable de 4096; longitudes mayores requieren revisión. Una fecha tipada con hora se rechaza en el asistente para evitar proponer una conversión que pierda la hora. El editor manual sigue disponible. Tipos físicos existentes proceden del destino autorizado; campos sin correspondencia se avisan y guardar conserva la validación actual. La clave no se adivina y la unicidad se comprueba en la preparación actual.
