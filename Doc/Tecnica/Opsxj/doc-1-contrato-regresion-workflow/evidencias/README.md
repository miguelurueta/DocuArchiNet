# Evidencias DOC-1

Esta carpeta está reservada para capturas y registros obtenidos en un ambiente autorizado. No contiene evidencia fabricada desde el análisis estático.

La [validación local de 2026-08-10](2026-08-10-validacion-local.md) registra suite, compilación y checks estructurales. No sustituye las capturas funcionales de navegador.

## Convención de nombre

`YYYYMMDD-HHMM_<caso>_<viewport>_<estado>_<entorno>.<ext>`

Ejemplo: `20260810-1430_R-04_1024_documento-seleccionado_QA.png`.

## Metadatos mínimos por ejecución

- JIRA-00/corte de línea base y commit o versión desplegada.
- URL o identificador del ambiente, navegador y resolución.
- Cuenta enmascarada y conjunto de datos de prueba.
- Caso de la matriz, resultado esperado/observado y fecha.
- Para R-09, secuencia de las tres actualizaciones parciales.
