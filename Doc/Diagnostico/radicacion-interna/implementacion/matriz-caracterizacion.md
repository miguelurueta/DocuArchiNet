# Matriz de caracterización del núcleo de radicación interna

Estado: casos previstos de P01, 2026-11-26. Esta matriz no es evidencia de una ejecución de dominio. El implementador registra condiciones/datos descartables autorizados, comando/recorrido, resultado anterior, resultado posterior y límites antes de aceptar una modificación compartida. Cambios funcionales acordados se identifican; no se llama regresión a cualquier diferencia ni se corrige almacenamiento congelado.

Fuentes: [diagnóstico general](../diagnostico.md), [servicio compartido](../diagnostico-webservice-radicacion.md), [almacenamiento/metadatos](../diagnostico-almacenamiento-metadatos.md) y [mapa de funciones](../mapa-funciones-implementacion.md). Leer el runbook aplicable antes de una prueba autenticada; no guardar credenciales/cookies/tokens ni cadenas de conexión. Los controles de ambiente son SELECT.

## Criterios para registrar resultados

Cada evidencia futura identifica caso, requisito, paquete, firma/revisión de código y ambiente autorizado; distingue observación anterior, expectativa, resultado posterior, efectos y limitaciones. No copiar datos sensibles ni evidencia de DOC-127 como prueba propia.

El guard de fuentes debe pasar antes y después; si falla, no se modifica la baseline para continuar. Si una prueba funcional revela un defecto de almacenamiento congelado, documentarlo y mantener pendiente la integración que dependa de corregirlo. No aplicar la corrección dentro de esta mejora.

P01 ejecuta solo la línea base local indicada en [su resultado](P01-resultado.md). La comparación funcional del núcleo y del almacenamiento sigue pendiente para los paquetes funcionales y los ambientes autorizados.
