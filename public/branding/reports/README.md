# Branding de Reportes

Esta carpeta contiene los assets corporativos usados por la exportacion de reportes del ecosistema `AppTable`.

## Convencion actual

- logo corporativo por defecto para reportes:
  - `company-report-logo.png`

## Reglas

- el asset debe permanecer versionado en el repo
- debe ser apto para encabezados de reportes en formatos ejecutivos
- no debe depender de rutas locales del equipo ni de recursos externos
- si se reemplaza el archivo, debe mantenerse el mismo nombre para preservar compatibilidad

## Uso esperado

- frontend client-side
- exportacion server-side
- encabezados de reportes con metadata institucional
